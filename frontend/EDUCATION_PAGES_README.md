# Образовательные страницы кафедры неврологии

## Обзор

Созданы страницы для всех образовательных программ кафедры неврологии на основе информации с официального сайта [http://www.kremlin-neurology.ru/edu.htm](http://www.kremlin-neurology.ru/edu.htm).

## Созданные страницы

### 1. Ординатура (`/education/ordinatura`)
- **Путь:** `frontend/src/pages/Education/Ordinatura.vue`
- **Описание:** Программа профессиональной переподготовки по специальности "Неврология"
- **Длительность:** 2 года обучения
- **Форма:** Очная
- **Специальность:** 14.01.11 - "Неврология"
- **Место проведения:** ГКБ №51 ДЗМ

**Содержание:**
- Программа ординатуры
- Учебный план (теоретическая и практическая подготовка)
- Требования к поступающим
- Контакты для поступления

### 2. Аспирантура (`/education/aspirantura`)
- **Путь:** `frontend/src/pages/Education/Aspirantura.vue`
- **Описание:** Научно-исследовательская подготовка для получения ученой степени
- **Длительность:** 3 года (очная), 4 года (заочная)
- **Форма:** Очная и заочная
- **Специальность:** 14.01.11 - "Неврология"

**Содержание:**
- Программа аспирантуры
- Научные направления (нейродегенеративные заболевания, сосудистая неврология, эпилептология, нейроиммунология)
- Учебный план
- Требования к поступающим
- Итоговая аттестация

### 3. Профессиональная переподготовка (`/education/professional-retraining`)
- **Путь:** `frontend/src/pages/Education/ProfessionalRetraining.vue`
- **Описание:** Программы повышения квалификации для врачей-неврологов
- **Объем:** 504 часа в год
- **Форма:** Очно-заочная с применением дистанционных технологий

**Содержание:**
- Доступные программы (базовый курс, сосудистая неврология, нейродегенеративные заболевания, эпилептология)
- Формат обучения
- Итоговая аттестация
- Требования к слушателям

### 4. Сертификационные циклы (`/education/certification-cycles`)
- **Путь:** `frontend/src/pages/Education/CertificationCycles.vue`
- **Описание:** Повышение квалификации для получения сертификата специалиста
- **Объем:** 144 часа в год
- **Форма:** Очно-заочная с дистанционными элементами

**Содержание:**
- Доступные циклы (клиническая неврология, сосудистая неврология, нейродегенеративные заболевания, эпилептология)
- Формат обучения
- Расписание занятий
- Итоговая аттестация

### 5. Тематическое усовершенствование (`/education/thematic-improvement`)
- **Путь:** `frontend/src/pages/Education/ThematicImprovement.vue`
- **Описание:** Специализированные курсы по актуальным вопросам неврологии
- **Объем:** 72 часа
- **Форма:** Очно-заочная с дистанционными элементами

**Содержание:**
- Доступные курсы (нейрореабилитация, нейрофизиология, нейроонкология, нейрохирургия, нейрофармакология, детская неврология)
- Формат обучения
- Расписание занятий
- Итоговая аттестация

## Дизайн и стилизация

### Общие характеристики:
- **Адаптивный дизайн** для всех устройств
- **Современный UI** с градиентными фонами и тенями
- **Интерактивные элементы** с hover-эффектами
- **Единообразный стиль** для всех страниц
- **Иконки и эмодзи** для визуального разделения

### Цветовые схемы:
- **Ординатура:** Сине-фиолетовые градиенты
- **Аспирантура:** Розово-красные градиенты
- **Профессиональная переподготовка:** Сине-голубые градиенты
- **Сертификационные циклы:** Голубые градиенты
- **Тематическое усовершенствование:** Оранжево-персиковые градиенты

## Технические особенности

### Компоненты:
- Используют Vue 3 Composition API
- Включают мета-информацию для SEO
- Адаптивная верстка с CSS Grid и Flexbox
- SCSS стили с переменными и миксинами

### Производительность:
- Ленивая загрузка компонентов через роутер
- Оптимизированные CSS и JavaScript бандлы
- Минифицированные ассеты для продакшена

## Запуск и тестирование

1. **Форматирование кода:**
   ```bash
   cd frontend
   npm run format
   ```

2. **Сборка проекта:**
   ```bash
   npm run build
   ```

3. **Запуск в режиме разработки:**
   ```bash
   npm run dev
   ```
