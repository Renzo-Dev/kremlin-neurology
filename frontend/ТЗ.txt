3. АРХИТЕКТУРА СИСТЕМЫ
================================================================================

3.1. Текущая архитектура:
Backend: PHP с MVC-подобной структурой
- Controllers: FileController, CatalogController, AuthController

- Middleware: AuthMiddleware, ValidationMiddleware

7. ИНТЕРФЕЙСЫ И API
================================================================================

Используем существующие API эндпоинты:

Публичные:
GET    /api/catalog/public    - список публичных файлов
GET    /api/catalog/private   - список приватных файлов (требует аутентификации)
POST   /api/download          - скачивание публичных файлов
POST   /api/privateDownload   - скачивание приватных файлов (требует аутентификации)

Новые эндпоинты (простые):
POST   /api/library/verify-password  - проверка пароля для приватной библиотеки
GET    /api/library/search?q=запрос  - поиск по файлам

8. ДАННЫЕ И СТРУКТУРЫ
================================================================================

Используем существующую структуру каталога (data/catalog.json):

{
  "files": [
    {
      "title": "Название файла",
      "authors": "Автор",
      "fileName": "файл.pdf",
      "uploadDate": "2024-01-01 12:00:00",
      "fileSize": 1024000,
      "type": "pdf",
      "isPublic": true/false
    }
  ]
}

Пароль для приватной библиотеки: хранить в отдельном файле или константе.
