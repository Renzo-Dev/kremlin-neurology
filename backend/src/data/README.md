# Архитектура каталогов

## Структура

```
data/
├── public/           # Публичная библиотека (статичная)
│   └── catalog.json  # Каталог публичных документов
└── private/          # Приватная библиотека (изменяемая)
    └── catalog.json  # Каталог приватных документов
```

## Принципы работы

### Публичный каталог (`public/catalog.json`)
- **Статичный** - никогда не изменяется
- Содержит базовые медицинские документы
- Доступен всем пользователям без аутентификации
- 15 документов по неврологии

### Приватный каталог (`private/catalog.json`)
- **Динамический** - файлы добавляются/удаляются
- Содержит пользовательские документы
- Требует аутентификации для доступа
- Изначально пустой `[]`

## API Endpoints

### Получение каталогов
- `GET /api/catalog/public` - публичный каталог
- `GET /api/catalog/private` - приватный каталог (требует аутентификации)
- `GET /api/catalog/paginated` - каталог с пагинацией
- `GET /api/catalog/paginated?type=public` - публичный каталог с пагинацией
- `GET /api/catalog/paginated?type=private` - приватный каталог с пагинацией

### Управление файлами
- `POST /api/catalog` - добавление файла в приватный каталог (требует аутентификации)
- `DELETE /api/catalog` - удаление файла из приватного каталога (требует аутентификации)

### Скачивание файлов
- `POST /api/download` - скачивание публичных файлов
- `POST /api/privateDownload` - скачивание приватных файлов (требует аутентификации)

### Дополнительные функции
- `GET /api/storage/stats` - статистика хранилища
- `POST /api/file/info` - информация о файле

## Логика работы

1. **Чтение**: `CatalogService::getCatalog($type)` загружает данные из соответствующего файла
2. **Запись**: Все изменения происходят только в `private/catalog.json`
3. **Фильтрация**: Нет необходимости - каждый каталог содержит только свои файлы
4. **Пагинация**: Поддерживается для обоих типов каталогов

## Преимущества новой архитектуры

- ✅ Простота - нет сложной логики фильтрации
- ✅ Производительность - загрузка только нужного каталога
- ✅ Безопасность - четкое разделение публичного и приватного
- ✅ Масштабируемость - легко добавлять новые типы каталогов
- ✅ Поддержка - простая структура файлов
