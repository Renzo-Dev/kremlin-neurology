# Библиотека файлов кафедры неврологии

## Структура

```
data/
├── public/          # Публичные файлы (доступны всем)
│   └── catalog.json
├── private/         # Приватные файлы (требуют пароль)
│   └── catalog.json
└── files/           # Физические файлы (не используется)
    ├── public/
    └── private/
```

## Доступ к приватной библиотеке

### Пароли для доступа:
- **Обычный доступ**: `123123`
- **Админ доступ**: `admin`

### API endpoints:
- `POST /api/auth` - аутентификация по паролю
- `GET /api/auth` - проверка статуса аутентификации
- `GET /api/catalog/private` - приватный каталог (требует аутентификации)
- `GET /api/catalog/private/paginated` - приватный каталог с пагинацией

## Формат каталога

Каждый файл в каталоге содержит:
```json
{
  "title": "Название файла",
  "authors": "Авторы",
  "fileName": "имя_файла.ext",
  "uploadDate": "2024-01-15 10:30:00",
  "fileSize": "2.5MB",
  "description": "Описание файла"
}
```

## Безопасность

- Приватные файлы доступны только после аутентификации
- Пароли хранятся в коде (в продакшене использовать переменные окружения)
- Сессии хранятся в памяти (в продакшене использовать Redis/БД)
