# Проект: Kremlin Neurology

"Это проект на базе Vue.js с использованием современных технологий для создания интерактивного веб-приложения."

## 📦 Стек технологий

- **Фреймворк**: Vue 3.5.13
- **Роутинг**: Vue Router 4.5.0
- **Слайдер**: Swiper.js 11.2.0
- **Сборка**: Vite 6.0.7
- **Стилизация**: SCSS 0.2.4, Sass 1.83.1
- **Форматирование и стиль кода**: Prettier 3.4.2

---

## 🚀 Установка и запуск

### 🔧 Требования

Для запуска проекта потребуется:

- Node.js LTS (например, версия 18.x.x)
- npm (устанавливается вместе с Node.js)

### 📥 Установить зависимости:

Для установки всех требуемых пакетов выполните команду:

```bash
npm install
```

### ▶ Запуск проекта в режиме разработки:

Выполните команду:

```bash
npm run dev
```

После выполнения проект откроется в браузере (по умолчанию `http://localhost:3000`).

### 💾 Сборка проекта:

Для создания production-версии выполните:

```bash
npm run build
```

Собранный проект будет доступен в папке `dist`.

## ⚙ Основные возможности

- Реализация лендинга/SPA на основе Vue.js
- Поддержка адаптивного дизайна (SCSS, Sass)
- Слайдеры и карусели с использованием Swiper.js
- Быстрая сборка и разработка через Vite.js
