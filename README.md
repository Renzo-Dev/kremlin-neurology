# Кафедра неврологии ФГБУ ДПО "ЦГМА" УД Президента РФ

Официальный сайт кафедры неврологии Центральной государственной медицинской академии Управления делами Президента РФ.

## 🏥 О проекте

Веб-приложение для кафедры неврологии, включающее:
- Информацию о кафедре и сотрудниках
- Образовательные материалы и конференции
- Школу молодых неврологов
- Научные исследования и публикации
- Контактную информацию

## 🛠 Технологии

### Backend
- **Laravel** - PHP фреймворк
- **PostgreSQL** - база данных
- **REST API** - архитектура

### Frontend
- **Vue 3** - прогрессивный JavaScript фреймворк
- **Vue Router** - маршрутизация
- **SCSS** - препроцессор стилей
- **Vite** - сборщик проекта

## 🚀 Установка и запуск

### Предварительные требования
- Node.js 16+
- PHP 8.1+
- Composer
- PostgreSQL

### Backend (Laravel)
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

### Frontend (Vue 3)
```bash
cd frontend
npm install
npm run dev
```

## 🔧 Разработка

### Добавление новых страниц
1. Создайте компонент в `frontend/src/pages/`
2. Добавьте маршрут в `frontend/src/router/routers.js`
3. Обновите навигацию

### Стилизация
- Используйте SCSS для стилей
- Следуйте принципам адаптивного дизайна
- Придерживайтесь цветовой схемы проекта

### Компоненты
- Создавайте переиспользуемые компоненты
- Используйте props для передачи данных
- Добавляйте TypeScript типы при необходимости
