# kremlin-neurology

## О проекте

**kremlin-neurology** — это веб-платформа, разработанная для автоматизации и поддержки деятельности в сфере неврологии. Проект реализован с использованием современных технологий веб-разработки: Vue, SCSS, PHP и JavaScript.

Платформа предназначена для специалистов и организаций, работающих в области неврологии, и предоставляет удобные инструменты для ведения медицинских данных, анализа, коммуникации и взаимодействия между участниками процесса.

## Основные возможности

- Удобный интерфейс для работы с медицинскими данными
- Интеграция с внешними сервисами и базами данных
- Автоматизация рутинных задач и процессов
- Поддержка различных ролей пользователей (врачи, администраторы и др.)
- Безопасное хранение и обработка информации

## Технологии

- **Vue** (55.3%) — клиентская часть, обеспечивает интерактивный UI
- **SCSS** (26.5%) — стилизация и оформление интерфейса
- **PHP** (12.9%) — серверная часть, бизнес-логика и API
- **JavaScript** (4.8%) — дополнительная логика на клиенте
- **Docker** — контейнеризация приложения
- **HTML, CSS** — базовая разметка и стили
