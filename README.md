# 🧠 Кафедра неврологии ФГБУ ДПО "ЦГМА" УД Президента РФ

> Официальный веб-сайт кафедры неврологии Центральной государственной медицинской академии Управления делами Президента РФ

## 🏥 О проекте

Современный веб-сайт кафедры неврологии, предоставляющий:

- **Информационный портал** о кафедре и сотрудниках
- **Образовательная платформа** с материалами и конференциями
- **Научная база** исследований и публикаций
- **Школа молодых неврологов** с расписанием мероприятий
- **Библиотека** методических материалов
- **Клиентская база** для работы с пациентами

---

## 🚀 Быстрый старт

### Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/your-org/kremlin-neurology.git
cd kremlin-neurology

# Frontend
cd frontend
npm install
npm run dev

# Backend
cd ../backend
npm install
npm run dev
```

### Проверка работы
- Frontend: http://localhost:5173
- Backend: http://localhost:8000

## 🔧 Разработка

### Добавление новых страниц

1. **Создание компонента** в `frontend/src/pages/`
2. **Добавление маршрута** в `frontend/src/router/`
3. **Обновление навигации** в Header компоненте

### Стилизация
- Используйте SCSS для стилей
- Следуйте принципам адаптивного дизайна
- Придерживайтесь минималистичного стиля
